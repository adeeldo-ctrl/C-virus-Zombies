# C virus Zombies

Godot 4.x third-person 3D prototype for the approved Android zombie-survival game plan.

## Current scope
- Basic third-person player movement and follow camera.
- A simple zombie AI that approaches the player.
- A small greybox test area to validate the technical foundation.

## Run
1. Install Godot 4.x.
2. Import this folder using the Godot Project Manager.
3. Open `project.godot` and run the main scene (F6/F5).

## Controls
- WASD / Arrow keys: move
- Space: jump
- Mouse: camera look (click the game window to capture the mouse; Esc releases it)

## Important status
All primitive meshes are temporary greybox placeholders. They are not the approved final realistic hero, zombie, city, vehicle, or animation assets. Android touch controls, Pakistani vehicles, Urdu voice acting, story missions, and APK packaging are not implemented yet.

See [MASTER_PLAN.md](MASTER_PLAN.md) and [DEVELOPMENT_LOG.md](DEVELOPMENT_LOG.md) for requirements and progress.
