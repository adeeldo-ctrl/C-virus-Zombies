# Browser prototype (Babylon.js)

This is the new engine path for C virus Zombies. It runs in a modern browser and does not require the Godot editor.

## Run locally
Serve the repository's `web` folder with any static HTTP server, then open `index.html` through that server. The page loads Babylon.js from its official CDN, so an internet connection is needed on first load.

## Prototype controls
- Desktop: WASD / arrow keys to move; drag on the right side of the screen to rotate the camera.
- Touch: use the on-screen left joystick to move; drag the right side to look around.
- Objective: avoid the walkers and reach the green safe zone.

## Current limitations
This is a technical greybox prototype, not final game art. Characters and buildings are simple generated meshes. It has no combat mechanics, finished story, Urdu voice acting, full city, vehicle system, or Android APK. Validate on target devices before making performance or delivery claims.
